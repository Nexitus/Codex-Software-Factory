# Example feature request

Build a small, accessible task-list feature into the existing application.

## Outcomes
- A user can add a task, mark it complete, and delete it.
- A user can recover gracefully from invalid input.
- Behavior remains functional across refresh when the app already supports persistence.

## Constraints
- Follow existing architecture, accessibility, and styling conventions.
- Add tests for main flows and failures.
- Do not modify production credentials or external services.
- Any assumption about persistence must be made explicit.
