## Task 6 test coverage added

`tests/test_distribution.py` runs the installed CLI from a foreign directory with `PYTHONPATH` removed for both the direct wheel and the wheel rebuilt from the sdist. The Windows run passed all 6 distribution tests against Task 5 source `d067d3e649bb4fb57d46431719d559a3e33bc9e5` plus the Task 6 test diff. The consumer fixture initializes an existing Unicode/space Git checkout with Codex selected, confirms the default config is unready, checks empty status, keeps all four required gates, configures a meaningful consumer-contract unittest, Ruff lint and security-rule checks, and compileall, then runs each fixture gate. A marker-writing Codex placeholder is scoped to readiness checks and is not invoked. After commit, the installed CLI runs a dry run, checks status, and confirms the consumer tree remains clean. This is a local artifact check, not native-host, provider, Linux, or live-run qualification.

## Platform and provider boundary

The initial support target is Windows PowerShell 7 and Linux. macOS is not qualified. The initial release uses Codex only: GPT Sol for planning/build orchestration and GPT Luna for Builder/specialists. Installed-package and mocked subprocess tests do not qualify Codex Desktop or Codex CLI as native hosts; each host still needs its own evidence. Claude Code and OpenCode are source templates only for this release.
